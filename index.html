API Documentation

Calendar Operations

Get current date/time, perform date arithmetic, and calculate differences between dates.

GET /api/v1/calendar/date
GET /api/v2/calendar/date
POST /api/v2/calendar/add
POST /api/v2/calendar/diff

Astronomy Services

Calculate moon phases, solar positioning, and moonlight intensity for any location and time.

GET /api/v2/calendar/moon-phase
POST /api/v2/calendar/solar
POST /api/v2/calendar/moonlight

Authentication

Secure GitHub OAuth integration with API key management and user identity tracking.

GET /api/auth/login
GET /api/auth/callback

Health & Monitoring

Built-in health checks and monitoring endpoints for system status and diagnostics.

GET /api/health
GET /api/debug

Quick Start Example

# Get current date curl -H "Authorization: Bearer YOUR_API_KEY" \ https://api.callableapis.com/api/v1/calendar/date # Get detailed date/time with timezone curl -H "Authorization: Bearer YOUR_API_KEY" \ https://api.callableapis.com/api/v2/calendar/date # Calculate moon phase curl -H "Authorization: Bearer YOUR_API_KEY" \ https://api.callableapis.com/api/v2/calendar/moon-phase # Get solar information for a location curl -X POST -H "Authorization: Bearer YOUR_API_KEY" \ -H "Content-Type: application/json" \ -d '{"lat": 37.7749, "lon": -122.4194}' \ https://api.callableapis.com/api/v2/calendar/solar
